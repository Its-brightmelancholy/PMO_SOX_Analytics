# PMO + SOX Compliance Analytics Platform

A end-to-end data analytics portfolio project simulating a real enterprise PMO and SOX compliance tracking system.

---

## 📌 Project Summary

Large organizations managing multiple projects and SOX compliance controls often rely on disconnected spreadsheets — creating risks of data inaccuracy, delayed reporting, and compliance gaps.

This project builds a fully integrated **PMO + SOX Analytics Platform** that automates data consolidation, generates real-time KPIs, and delivers executive-ready dashboards.

---

## 🎯 Business Objectives

- Track 30+ active projects across budget, schedule, and milestone performance
- Monitor 50+ SOX compliance controls and their testing status
- Manage audit findings from identification through remediation
- Deliver real-time KPI dashboards to executive and audit committee audiences
- Automate reporting workflows to eliminate manual effort

## 📊 Dataset

Five interconnected tables modelling a real enterprise PMO and SOX environment:

| Table | Rows | Description |
|---|---|---|
| Projects | 30 | Active and completed projects with budget and schedule data |
| Controls | 50 | SOX compliance controls with risk ratings and evidence status |
| Audit Findings | 40 | Control failures with severity, ownership, and remediation tracking |
| Milestones | 30 | Project deliverables with planned vs actual completion dates |
| Budget Tracking | 30 | Monthly planned vs actual spend per project |

---

## 📈 KPIs Tracked

**PMO Performance**
- On-Time Delivery Rate
- Schedule Variance (days)
- Milestone Completion Rate
- Budget Variance %

**SOX Compliance**
- Control Testing Coverage
- Control Pass Rate
- Audit Finding Rate
- Remediation Rate
- High Risk Finding Aging (days)
- Evidence Collection Rate
